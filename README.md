# Ndefo Paul Auguste - Portfolio

A modern, responsive portfolio website showcasing my work as a Full Stack Developer.

## 🚀 About Me

Full Stack Developer specializing in React, TypeScript, and JavaScript. Currently pursuing a Bachelor's Degree in ICT at ICT University, with professional experience from Zen Africa.

## 🛠️ Built With

- **React** - UI Framework
- **TypeScript** - Type Safety
- **Vite** - Build Tool
- **Tailwind CSS** - Styling
- **Lucide React** - Icons

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
